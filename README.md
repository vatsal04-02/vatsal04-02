Every graphic above is generated by this repo's own code, not pulled from<br>
a third-party card service. <samp>portrait.svg</samp> is a photo run through<br>
a character ramp by <samp>scripts/generate_portrait.py</samp>; the stats<br>
graphics and these section headings are drawn by <a href="./.github/workflows/refresh-stats.yml">a scheduled GitHub Action</a>,<br>
once a night, straight from the GitHub GraphQL API — committing only when<br>
the numbers actually change.

They animate with SMIL inside the SVG, since GitHub strips `<script>` tags<br>
from READMEs, and since nothing loads from a third party, nothing here can<br>
rate-limit or go dark. The headings are images for the same reason: GitHub<br>
also strips `<style>` and `class=`, so an image is the only way to put a<br>
custom typeface on a heading.
